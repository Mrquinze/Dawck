# Dawck

A macOS utility for customizing your Dock, including secondary, independently configurable Dock-like panels alongside the system Dock, and full customising options for the main dock.

## Requirements

- macOS 14.0 or later

## Installation

1. Download the latest "Dawck-x.y.dmg" and copy the app to /Applications.
2. **First launch:** this build is signed but not notarized (that requires a paid Apple Developer Program membership). macOS will refuse to open it with a normal double-click the first time. Right-click `Dawck.app` → **Open** → **Open** in the confirmation dialog. You only need to do this once per version. (Or: **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.)
3. Choose how DockCraft appears — Dock icon, menu bar item, or both — from its main window.
